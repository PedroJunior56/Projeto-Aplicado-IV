- `cd_projeto_aplicado_IV_doc.ipynb` — documentação, EDA, modelagem, validação e resultados.

### Modelos avaliados

- Seasonal Naive
- SARIMA
- Random Forest recursivo

O projeto utiliza dados semanais de dengue do estado de São Paulo e compara modelos de séries temporais e aprendizado de máquina por meio das métricas MAE, RMSE e MASE.
